# Frozen-evidence legacy archive map repair v7

This is a standalone, isolated map-only repair source, not a company-runtime replacement. It imports no earlier revision. The caller supplies one public repository, its hash-locked helper directory, the fixed modern map helper (SHA-256 9e95a7674e201488ca35263a7111d0535d3e50b1e59779226373991f28b50d7a), read-only canonical GPS, a private evidence manifest and a new separate output directory. The modern helper and its three dependencies are executed from verified source bytes; cached bytecode is not trusted. Paths, module metadata, verified bytes and template provenance are checked. No DB, export, saved-form, business renderer, navigation or publication writer is used.

## Evidence and preservation

Each date is pinned to full current/source commits, exact paths, Git blobs, SHA-256 digests, checkout bytes, identity and complete span. Source extra identities require explicit exclusion records. Current business HTML is retained byte-for-byte. Only missing map roles are restored, using original published map evidence validated against GPS. Existing URLs, endpoint objects, names, representative objects and handlers are preserved. The sole routine retained-control markup exception appends a missing btn-map-single or btn-map-two class, recorded per control. No other class or CSS/JavaScript edit is permitted. Actual ordinary parse_page and the dedicated actual reader must return equal MapViews.

Actual map controls, payloads, panels/canvases, overall section, visibility attributes and handler targets obey strict schemas. The overall section must equal a literal from the verified renderer source. Unknown/extra/outside-card map nodes, nonzero invalid data, conflicting source/GPS values, ambiguous identities, changed hashes, unsafe URLs and untracked imports stop the batch. Source non-map damaged heading chrome is not used; all complete card fragments and points remain strictly checked. Whitespace-only span equivalence does not change numbers, directions, words or punctuation, and normalized collisions are refused.

## Execution and delivery

CLI: --manifest --repo --scripts --gps --modern --output. All pages preflight before a new isolated staging directory is renamed to the new output. Existing output and output inside input repositories/resources are refused. Failure never leaves a partially approved publication batch.

Tests use LEGACY_TEST_ROOT, LEGACY_TEST_REPO, LEGACY_TEST_MODERN, LEGACY_TEST_GPS, LEGACY_TEST_MANIFEST and optional LEGACY_PREVIOUS_FREEZE. Use the private full regression manifest for the combined fixture suite, and the private final-four manifest for the four-page release candidate. Older approved outputs must be byte-identical.

Only this document, repair_legacy_archive_maps.py and test_legacy_archive_maps.py are public implementation artifacts. Private manifests, receipts, source inventories, preparation scripts and absolute local paths are not publication artifacts. Shared fixed dependencies must accompany the final source or be passed from the same published repository; copying this file alone does not supply them.

Normal prepare_archive_maps is not claimed compatible: unchanged midpoint/end policy checks can fail closed. No common guard or company bundle is changed to suppress that failure. Real browser/map-click/printing checks were not performed because the browser connection was unavailable. Static correctness is not an interactive test or runtime-adoption claim.
