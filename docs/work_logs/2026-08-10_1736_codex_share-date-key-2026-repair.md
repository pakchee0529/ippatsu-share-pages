# 来週共有ページの日付キー修正

## 原因

- 2026年8月19日から21日の9件が、共有ページと `cases.share_date_key` の双方で `280819` から `280821` として登録されていた。
- そのため、ポータルトップでは2028年の予定として8月24日以降に表示されていた。

## 修正

- ケースの日付キーを `260819` から `260821` に訂正した。
- `share_display_order` を維持して週間予定テーブルを復元した。
- 公開ディレクトリを `share/260819` から `share/260821` へ移動し、ポータルトップのリンクと表示年を2026年へ訂正した。

## 検証

- 9件の管理番号・径間・作業内容・本数・備考・地図情報は移動前後で一致した。
- 週間予定テーブルの順番は、8月19日が4件、20日が3件、21日が2件でそれぞれ `1..n` を確認した。
