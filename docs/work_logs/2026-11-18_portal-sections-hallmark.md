# 共有ポータルの業務一覧をHallmarkで整える

現調待ち・交渉待ち・付託待ち・案件管理・完了アーカイブの入口、地域別一覧、案件詳細に、TOPと同系統のスタイルを適用する。検索欄の余白、案件名と状態の読みやすさ、スマホでの一覧の並びを整える。

184件の既存HTMLはスタイル参照の1か所を除いてバイト一致。生成元も同じ参照を追加し、既存のリンク、検索、地図、状態変更処理、保存済み帳票を保持する。入力データの取り直しによる件数変動を避けるため、公開候補への適用は取得済みHTMLへの限定差分とした。

隔離したChromeで代表12画面を320・390・1280pxで確認。メニュー、案件番号検索、案件詳細へのリンク、アーカイブの日付一覧と設計番号検索を検査した。本番への状態変更送信は検査対象外。

アーカイブ生成の変更前後を別ステージで比較し、差分が入口のスタイル参照のみであることを確認した。既存の全アーカイブ再現検査では変更前から日付別view 11件が現行公開ファイルと不一致であり、このPRでは日付別viewを変更しない。
