# 写真番号範囲指定と保存導線

- 写真番号の共通パーサーを追加。05-10,15、全角数字、〜/～に対応。逆順・000・1000・重複は理由を表示して拒否。
- E20/N20以上、運搬、倒木実費、自由記述は範囲を写真単位へ展開。E10/N10は従来どおり写真ごとの本数ボタン。
- ポータルはバナーのみ、取込後のPC修正画面は回転・バナーを撮影日と範囲で一括指定。既存の同じ撮影日/番号へ統合し、変更しない指定では他方の補正を保持。別日の同番号は別写真。ユーザー訂正により、ポータルでは向きの入力欄を表示しない。
- ポータル保存の説明を独立表示。画面下の保存ボタンを「ポータルに保存」に簡潔化し、端末保存だけではPCに届かないことを説明。PC修正画面は「修正をPCに保存」と表示。
- 範囲/重複/日またぎ/補正統合のJSテスト成功。PC側テスト12件成功。ローカルブラウザで05-10の6枚一括補正、保存と読戻しを確認。
- 既存版、原本写真、業務DBの予定は変更しない。補正は台帳用コピーに適用。
